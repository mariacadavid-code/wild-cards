# Código Wild Cards

Página de bienvenida del mini curso de HTML para grado 6° de Ser School.

- Sitio: https://mariacadavid-code.github.io/wild-cards/
- El botón "Iniciar sesión" lleva al curso (Apps Script), que pide el correo @serschool.edu.co.

La página se genera desde `9°/wild-cards/landing/plantilla.html` con `node landing/construir.js` (carpeta `landing/sitio/`). Este repositorio no guarda datos de estudiantes.
